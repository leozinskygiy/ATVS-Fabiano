# Exercícios Básicos de Python 🐍

Este repositório contém resoluções de 10 exercícios fundamentais de lógica de programação em Python.

## 📋 Lista de Exercícios

1. **`q01_entrada_saida.py`**: Leitura de nome e idade com saída formatada.
2. **`q02_operacoes_aritmeticas.py`**: Operações matemáticas básicas (+, -, *, /).
3. **`q03_par_ou_impar.py`**: Verificação de paridade de um número.
4. **`q04_maior_numero.py`**: Comparação entre dois números inteiros.
5. **`q05_classificacao_triangulo.py`**: Validação e classificação de triângulos.
6. **`q06_contador_1_a_20.py`**: Estrutura de repetição `while` contando de 1 a 20.
7. **`q07_media_turma.py`**: Leitura de notas e cálculo de média com `for`.
8. **`q08_pares_1_a_50.py`**: Exibição de números pares no intervalo de 1 a 50.
9. **`q09_verificador_primo.py`**: Algoritmo para checar se um número é primo.
10. **`q10_bubble_sort.py`**: Ordenação de vetor utilizando o algoritmo Bubble Sort.

## 🚀 Como Executar

Para rodar qualquer um dos scripts, execute no terminal:

```bash
python q01_entrada_saida.py
```
